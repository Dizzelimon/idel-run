# Идел Run

Трёхмерный офлайн-раннер для Android. Стартуй в Казани, Свияжске или Мамадыше. Пробегай по крышам поездов, подбирай монеты-тюльпаны и открывай вещи в вокзальном ателье.

**[Скачать APK для Android 7.0 и новее](https://github.com/Dizzelimon/idel-run/raw/refs/heads/main/IdelRun-1.0.0.apk)**

[Скачать проект с исходниками](https://github.com/Dizzelimon/idel-run/raw/refs/heads/main/IdelRun-1.0.0-source.zip)

| Жест | Действие |
| --- | --- |
| Свайп влево или вправо | Смена пути |
| Свайп вверх | Прыжок |
| Свайп вниз | Подкат или быстрое приземление |
| Двойное касание или кнопка доски | Одиннадцать секунд защиты, до первого удара |

Рампа ведёт на крышу состава. Магнит притягивает монеты с соседних путей. Бонус ×2 удваивает очки. Реактивный ранец поднимает героя к воздушной цепочке монет, а пружинный бонус увеличивает высоту прыжка. Рекорд, баланс, покупки и надетые вещи сохраняются на устройстве. Музыку можно выключить с главного экрана и в паузе.

## Запуск и сборка

Браузерная версия открывается из `www/index.html`. На клавиатуре работают стрелки или WASD, пробел для прыжка, B для доски и P для паузы. В Android-приложении ресурсы загружаются локально через системный WebView.

Для повторной сборки на Linux x86_64 нужны Java 17+, Apktool 2.9.3, Android apksigner, unzip и Python 3. Задайте `APKTOOL_JAR`, `KEYSTORE`, `STORE_PASS` и при необходимости `KEY_ALIAS`, затем выполните `bash tools/build.sh`. Свой ключ выпуска храните отдельно. Сборка с другим сертификатом устанавливается после удаления версии с прежней подписью.

## Игровые материалы

Модель героя, аксессуары, вагоны и архитектура построены из собственной геометрии. Анимации, освещение и зацикленная музыка созданы для игры. Обложка выполнена по предоставленному фото. Панорамы трёх станций нарисованы для игры. Рендеринг использует Three.js r160 по лицензии MIT, текст лицензии включён в `www/three.LICENSE`.

Маршрут — художественная железнодорожная трасса. Ориентиры взяты из описаний Казани, Свияжска и Мамадыша на [Visit Tatarstan](https://www.visit-tatarstan.com/).
